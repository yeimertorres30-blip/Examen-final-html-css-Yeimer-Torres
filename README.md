# Eco Vida

Eco Vida es una plataforma web desarrollada en HTML y CSS que promueve hábitos sostenibles y el consumo responsable mediante la venta de productos ecológicos, contenido educativo y herramientas de concienciación ambiental.

## Descripción

El proyecto busca fomentar el cuidado del medio ambiente ofreciendo:

- Productos ecológicos reutilizables.
- Información sobre sostenibilidad.
- Calculadora de huella de carbono.
- Dashboard de impacto ambiental.
- Blog con consejos y artículos ecológicos.
- Promociones y suscripciones para la comunidad Eco Vida.

## Funcionalidades

### Página Principal
Presentación de la marca, misión y acceso a las diferentes secciones del sitio.

### Catálogo
Visualización de productos ecológicos organizados por categorías.

### Nosotros
Información sobre la empresa, misión, visión e historia.

### Blog
Artículos relacionados con:
- Reciclaje
- Energías renovables
- Hábitos sostenibles
- Cuidado del medio ambiente

### Calculadora de Huella de Carbono
Herramienta para estimar el impacto ambiental de las actividades diarias.

### Dashboard de Impacto
Visualización de indicadores relacionados con sostenibilidad y reducción de residuos.

### Promociones
Ofertas especiales y descuentos en productos ecológicos.

### Suscripción
Formulario para que los usuarios reciban noticias y promociones.

### Contacto
Canales de comunicación con la empresa.
